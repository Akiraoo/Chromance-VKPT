# Chromance-VKPT

[English](README.md) · [繁體中文](README.zh-TW.md) · **简体中文**

![Chromance-VKPT：黄昏的樱花林](figures/hero.jpg)

为 [Radiance](https://github.com/Minecraft-Radiance) 模组从零撰写的路径追踪光影包。画面追求温暖、带风格的氛围，
但光照完全由真实的路径追踪计算。

## 名称由来

**Chromance** = **Chroma** + **Radiance**。*Chroma* 是“色彩”：每支火把、每盏灯笼都带着自己的颜色照亮世界，
天空随时段变换色调，暖色阳光对上偏蓝的阴影。*Radiance* 既是这个光影包所服务的模组，也是路径追踪实际在计算的物理量，
也就是沿着每一条光线传递的光。**VKPT** 代表 **Vulkan Path Tracing**（Vulkan 路径追踪），也就是它背后的技术。

> 目前状态：**持续调整中**。四个开发阶段（核心、水与雨、云、曝光与拍照）都已完成，接下来以修正与调整画面为主。

## 功能

- **路径追踪光照**：日月光与柔和阴影、天空光、多次反弹的间接光。日月是主要光源，阴影清楚。
- **彩色方块光源**：火把、灯笼、萤石、岩浆等所有发光表面都以自己的颜色照亮周围。光源是直接采样而不是靠随机碰到，
  所以**移动时不会闪烁**。
- **有限的照明范围**：方块光在可调距离内衰减到零，火把只照亮一小块，外面维持黑暗，就像在黑暗中点亮打火机。
- **微弱发光只当装饰**：发光地衣、材质包的发光矿石等微弱光源画面上仍会发光，但缺省不再照亮洞穴
  （可用“弱发光照明”打开）。岩浆等强光源也调暗，不再让画面过曝。
- **洞穴**：在地底完全不计算太阳；有部分开口（竖井、洞口）时，依看得到多少天空按比例计算。洞穴雾气更暗更淡，
  地底的水也不再发光。
- **时段调色**：晴天深蓝的天空配上暖白的地平线、日出日落金黄、太阳刚下山／刚升起的蓝调时刻、昏暗的月夜。
- **阳光光束**：日光与月光穿过树叶、建筑与云缝形成的光束（丁达尔效应），另有屏幕空间的光束让地面上也看得到光柱。
  被山挡住的夕阳会是暗的剪影，光从边缘透出。
- **日月形状**：圆形或原版的方形，圆形月亮会显示月相。
- **labPBR 1.3**：光滑度、F0 与缺省金属、自发光、次表面散射（叶子透光）、法线贴图、环境光屏蔽。
- **玻璃**：清澈透明、染色玻璃带颜色；后方比较暗时（像夜晚的窗户）玻璃会像镜子一样反射。
- **水**：清澈、跟随生物群系变色的水，水上水下的反射与折射；缓慢移动的波纹（在降噪后才叠上，不会冻住或拖影）；
  水底焦散、水下光束与淡淡的蓝绿雾气；透明会折射的气泡。
- **下雨**：湿润反光的地面、水薄膜与积水；涟漪是几圈细细的波纹，大小不一、随机交叠，积水与开放水面都有；
  雨丝透明会折射。下雨时太阳被雨云遮住，不会有阳光阴影。
  只有真的会下雨、而且淋得到雨的地方会变湿（沙漠与雪地保持干燥），雨停后地面慢慢变干。
- **云**：体积云（晴天蓬松分散，下雨时合成灰色的整片云层）与移动的云影，或同样会投下阴影的原版方块云。
- **夜空**：星星会被云挡住，另有可选的淡淡彩色星云带。
- **眼睛适应**：走到阳光下先刺眼再快速恢复，进入黑暗要几秒才适应，洞穴依然是暗的。
- **掉落物与实体光源**：掉在地上的光源方块（萤石、火把、灯笼……）会照亮周围。
- **发光的生物眼睛**：末影人、蜘蛛、幻翼等生物的眼睛会发光，使用 Radiance 自带的眼睛发光贴图，
  不需要材质包，也不会把生物的身体照亮。
- **夜视**：夜视效果会柔和地提亮画面（水下也有效），而不是一片死白。
- **旁观者模式**：穿墙飞行时保持流畅，光线会跳过你所在的墙壁。
- **泛光与景深**：亮处柔和地发光；可选的景深，支持自动对焦（对准准星）或固定距离。
- **调色**：冷暖分离、电影感的画面张力、对比度、饱和度、暗角、胶片颗粒，以及去除 8 比特色带的处理。
- 支持 Radiance 的降噪器（DLSS 光线重建或 NRD）与画面放大器，建议使用 DLSS 光线重建。
- **远距离坐标**：在离原点上百万格的地方，水波、涟漪、积水、雨、焦散与云也不会因浮点精度不足而变成一格一格的马赛克。

## 需求

- Minecraft **1.21.4** 与 **Radiance 0.1.6-alpha**（Fabric）。
- 支持硬件光追的显卡（NVIDIA RTX 等），开发环境为 RTX 3080。
- 需保持 Radiance 的“区块发光收集”打开（缺省打开），方块光源依赖它；关闭时 Radiance 会改用内置光影包。

## 安装

1. 将光影包（文件夹或 zip）放入 `<游戏实例>/shaderpacks/`。
2. 在游戏中打开 Radiance 设置的光影包页面，选择 **Chromance VKPT**。
3. **更新光影包后，请在光影包设置页按“全部重设”**。Radiance 会在第一次加载时记住所有设置值，
   新的默认值要重设后才会生效。
4. **建议的 Radiance 色调映射设置**：打开“手动曝光”、“手动曝光 EV”设为 **0**、“曲线提亮上限”设为 **0**。
   Chromance 的亮度是按最终画面设计的，并由光影包自己的眼睛适应调整曝光；Radiance 的自动曝光与暗部提亮
   会把夜晚和雨天拉回接近白天的亮度。

## 设置总览

| 分类 | 内容 |
| --- | --- |
| 光照 | 间接光反弹次数、阳光／月光／天空光强度、环境天空光、阳光光束、阴影柔和度、最低亮度 |
| 方块光源 | 强度、照明范围、每个表面的光线数与候选数、采样亮度上限、掉落物与实体光源、弱发光照明 |
| 天空与时段 | 日月形状与大小、黄金时刻、蓝调时刻、夜晚亮度与色调、夜空星云 |
| 雾与水体 | 雾气、水的混浊度、生物群系水色、水面波纹、水下光束、云、云量、云的品质、云影 |
| 雨天 | 地面湿润、积水、涟漪、雨丝数量与不透明度 |
| 材质 | labPBR 贴图过滤、法线贴图强度、玻璃反射 |
| 相机 | 眼睛适应、适应程度、暗处适应上限、适应速度、景深（自动对焦、对焦距离、强度） |

## 已知限制

- 材质包的微弱发光贴图（例如发光矿石）即使关闭“弱发光照明”，仍在 Radiance 的光源清单内，
  画面内数量很多时（例如用透视看整个洞穴系统）会吃掉一些帧数。
- 不使用 DLSS 光线重建（改用 NRD）时，小光源与洞穴的杂讯较多，建议使用 DLSS 光线重建。

- 离原点非常远时（约一百万格以上），方块与光源本身的位置仍受 Minecraft 与 Radiance 的浮点精度限制，这部分光影包无法修正。
  光影包自己的水波、云等图案每 16384 格重复一次，跨过那条线时图案会跳一下。
